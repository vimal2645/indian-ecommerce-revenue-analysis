# 🛒 Indian E-Commerce Revenue Analysis

> End-to-end data analytics project on **30,000+ Indian e-commerce transactions**, delivering a Power BI dashboard that projects a **12% revenue uplift** through targeted marketing insights.

![Python](https://img.shields.io/badge/Python-3.10-blue?logo=python) ![Pandas](https://img.shields.io/badge/Pandas-2.0-150458?logo=pandas) ![Power BI](https://img.shields.io/badge/Power_BI-Dashboard-F2C811?logo=powerbi) ![SQL](https://img.shields.io/badge/SQL-Analysis-336791?logo=postgresql) ![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-orange?logo=jupyter)

## 🎯 Business Problem
An Indian e-commerce company needed to understand:
1. Which product categories drive the most revenue
2. Why 35% of records had null/duplicate entries
3. Which customer segments to target for maximum ROI
4. What marketing strategies could boost revenue

## 📊 Key Results
| Metric | Finding |
|--------|---------|
| 💰 Projected Revenue Uplift | **+12%** via targeted marketing |
| 🧹 Data Quality Improvement | **35% reduction** in nulls/duplicates |
| 📦 Records Analyzed | **30,000+ transactions** |
| 🎯 Customer Segments Found | 4 high-value segments identified |

## 🔍 Analysis Pipeline

```
Raw Data (30K+ records)
    ↓
1. Data Cleaning (EDA)      → 35% null/dupe reduction
    ↓
2. Exploratory Analysis     → Category & seasonality trends
    ↓
3. Customer Segmentation    → RFM analysis
    ↓
4. Statistical Modeling     → Revenue projections
    ↓
5. Power BI Dashboard       → Executive-ready visualizations
```

## 📈 Dashboard Features
- **Revenue Trends** — Monthly/quarterly breakdown
- **Category Performance** — Top/bottom product categories
- **Geographic Heatmap** — Regional revenue distribution
- **Customer RFM Analysis** — Recency, Frequency, Monetary
- **Marketing ROI Projector** — Scenario modeling for campaigns

## 💡 Key Insights
1. **Top 3 categories** account for 68% of total revenue
2. **Weekend purchases** have 22% higher AOV than weekdays
3. **Returning customers** (segment B) generate 3.4x more revenue per visit
4. **South India** shows highest growth potential (underpenetrated)
